## GLOBAL-PROPOSAL-004

**State:** idea

**Idea:** Evaluate optional export of crash bundles, logs, and telemetry when a concrete deployment requires off-device evidence collection.

**Rationale:** Remote evidence may help deployed unattended terminals, but no current requirement justifies a framework-owned backend or transport.

**Constraints:** Explicit ownership, redaction, identity, offline buffering, retry/backoff, bounds, credentials, and transport security; no backend in Core, dashboard in Diagnostics, remote administration in Watchdog, or cloud SDK in feature modules.

**Promotion target:** A demonstrated deployment requirement and a boundary/security review.
